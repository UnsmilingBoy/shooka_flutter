## inventory_forms_table.dart — client-side sorting finished

File: `lib/(tabs)/inventory_management/components/list/inventory_forms_table.dart`

Completed the in-progress sort feature (id + Jalali date columns).

- Implemented `_sortFormsById` (was a stub returning an undefined `sorted`).
  Ids are `int`, compared with `compareTo`, direction flipped by `ascending`.
- Replaced the dead `_DateSortLabel` with the generic `_SortHeaderLabel`
  (`label` + `active` + `ascending`), which the desktop `DataColumn`s already
  referenced but never defined.
- Kept `sortColumnIndex` unset on `DataTable` on purpose: Flutter always emits
  a `_SortArrow` when `onSort != null`, but it is only *visible* when
  `sortColumnIndex == columnIndex`. Leaving it null avoids a double arrow.
- Added `_SortBar` + `_SortChip` above the mobile card list, because card view
  has no clickable column header — sort state is shared with desktop.

Sort semantics: `_sortColumn == null` = server order; first tap on a column
sorts descending, next tap flips. Empty `dateOfReceipt` always sinks last.

## Device list export — flowchart columns missing

Files: `lib/services/export_service.dart`,
`lib/services/providers/device_provider.dart`

Symptom: flowchart columns added to the device export never appear.

Diagnosis (verified, not guessed):
- Proved the Excel write path is fine: loaded `assets/export.xlsx`, wrote
  cells at column 12+, saved, re-unzipped — values persisted as shared
  strings. `Sheet.cell()` does grow `_maxColumns`. Template already reserves
  M/N (cols 12–13) as empty placeholders.
- So `flowLabels` was empty → nothing written. Cause: the devices-list
  payload's `flowcharthistory` key was not producing entries.
- `flowcharthistory` appears NOWHERE else in the app. Per-device flowchart
  progress always comes from `POST /api/shouka/objects/flowchart/retrieve/`
  (`DeviceFlowchartStep`: `label`, `order`, `is_done`).

Fix:
- `_flowchartProgress()` reads history under 5 candidate keys and 4 shapes
  (List of maps, List of strings, label→bool map, single step map), with
  `_asDone` coercion (bool/num/"true"/"done", plus `done_at` implies done).
- `exportDevices(devices, {loadFlowchart})` — when no row carries history,
  falls back to the per-device endpoint, 8 concurrent workers.
  Wired in `DeviceProvider.exportDevicesToExcel`.
- Logs which path was taken plus device keys when nothing is found.

Note: the fallback is N requests (bounded concurrency). If exports routinely
cover thousands of devices, prefer having the backend include the field.
